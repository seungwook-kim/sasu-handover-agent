경로 추적 콜 트리

URL 하나가 어떤 코드와 SQL, 테이블을 거치는지 따라갑니다. 파일 위치를 누르면 코드를 볼 수 있습니다. 전체 구조는 프로젝트 지도에서 봅니다.

    보기 옵션
    추정 연결 동적 SQL ID를 문자열 앞부분으로 짐작해 이은 SQL이에요. 실제로 부르는 SQL과 다를 수 있어요. 저장소 밖 · 빈 이 저장소에 소스가 없는 빈(라이브러리 jar·설정 XML에만 정의)이에요. 안쪽은 따라가지 못해요. 없는 SQL 호출 이 메서드가 부르는 SQL ID가 Mapper에 없어요. 이 경로를 실행하면 오류가 나요.
